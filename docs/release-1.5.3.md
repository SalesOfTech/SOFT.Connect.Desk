# SOFT.Connect.Desk 1.5.3-soft.1 — подготовка

База: официальный тег RustDesk `1.5.3`, коммит `95cca3f66`.
Общая библиотека обновлена до upstream `fae47e024dd83cef6aaecde0aa7d11731df11649`
с сохранением наших серверов, ролей и каналов обновления. Версия Flutter:
`1.5.3-soft.1+72`, чтобы Android распознал обновление после build 71.

## Изменения для пользователя

- Исправления upstream для Windows-службы, установщика и IPC.
- Исправления macOS, Linux, Android, аудио, буфера обмена и удалённых сессий.
- Support и Operator, OAuth Operator, явный статус службы, брендинг и
  проверка SHA-256 артефактов сохранены.

## До стабильного тега

1. Пройти тестовые сборки обеих ролей на Windows x64/ARM64, macOS, Linux и Android.
2. Проверить Service status и установку Support на Windows; проверить OAuth Operator.
3. Проверить обновление от 1.5.0-soft.1 для каждой роли и платформы.
4. После Smoke-тестов создать preview, затем стабильный тег `v1.5.3-soft.1`.

Обычная сборка Actions не является релизом и не отправляет обновление клиентам.
