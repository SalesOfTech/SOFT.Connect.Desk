# SOFT.Connect.Desk 1.5.3-soft.1 — подготовка

База: официальный тег RustDesk `1.5.3`, коммит `95cca3f66`.
Общая библиотека обновлена до upstream `fae47e024dd83cef6aaecde0aa7d11731df11649`
с сохранением наших серверов, ролей и каналов обновления. Версия Flutter:
`1.5.3-soft.1+72`. В новый релиз входят только Windows, macOS и Linux.

## Изменения для пользователя

- Исправления upstream для Windows-службы, установщика и IPC.
- Исправления macOS, Linux, аудио, буфера обмена и удалённых сессий.
- Support и Operator, OAuth Operator, явный статус службы, брендинг и
  проверка SHA-256 артефактов сохранены.

## Установка на macOS

Для установки и обновления используется DMG. Пакеты подписаны локальной
подписью ad hoc, без Developer ID и нотариализации Apple.

1. Скачайте DMG для своей роли и архитектуры: `arm64` для Apple Silicon
   или `x86_64` для Intel. Используйте официальный GitHub проекта и сверьте
   SHA-256 с файлом `.sha256` из того же артефакта.
2. Откройте DMG, скопируйте `SOFT.Connect.Desk.app` в «Программы» и запустите
   приложение оттуда.
3. Если macOS сообщает, что разработчика не удалось проверить, откройте
   «Системные настройки → Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть» для SOFT.Connect.Desk. Это разрешение только для
   этого приложения. [Инструкция Apple](https://support.apple.com/ru-ru/102445).

Если контрольная сумма не совпадает, macOS сообщает о повреждении или
кнопки разрешения нет, не отключайте Gatekeeper: передайте в поддержку
точный текст сообщения.

Если Operator уже использовался на Mac, после обновления один раз войдите
через SOFT.Connect. Новая версия сохраняет сеанс одной записью в Связке
ключей и не запрашивает доступ к старым записям по очереди.

## До стабильного тега

1. Пройти тестовые сборки Support и Operator на Windows x64/ARM64, macOS x86_64/ARM64 и Linux.
2. Проверить запуск поставляемого приложения на обеих архитектурах Windows и macOS.
   Windows CI проверяет запуск приложения из собранного комплекта; macOS CI
   проверяет DMG, подпись, архитектуру и запуск скопированного из DMG приложения.
   Дополнительно проверить установку и статус службы Support, вход Operator и
   первый запуск скачанной версии `1.5.3-soft.1` из Finder с включённым
   Gatekeeper и штатным подтверждением для приложения.
   Для Operator на macOS дополнительно проверить повторный запуск с сохранённой
   сессией (не более одного запроса пароля Связки ключей), автоматическое
   обновление токена и выход без повторной серии запросов.
3. После проверок запуска создать preview, затем стабильный тег `v1.5.3-soft.1`.

Обычная сборка Actions не является релизом и не отправляет обновление клиентам.
