# SOFT.Connect.Desk 1.5.0-soft.1 — подготовка

База: официальный тег RustDesk `1.5.0`, коммит
`fada664df` (не nightly). Общая библиотека обновлена до upstream
`229b904508364c8997aad0fb5af57effac859f60` с сохранением наших настроек.
Версия Flutter: `1.5.0-soft.1+71`, чтобы Android обновлялся с build 70.

## Изменения для пользователя

- Над ID постоянно виден статус службы и доступности подключения.
- При остановленной службе или отсутствии ответа локального host-процесса:
  «Подключения недоступны» и кнопка «Включить службу».
- Нажатие не выдаёт ложное «Готово»: ожидается подтверждение через IPC.
  Отмена системного запроса/таймаут позволяет повторить запуск.
- Отдельно показана ситуация, когда служба работает, но связи с сервером нет.
- Авторизация Operator, отдельный Support, серверные настройки, иконки,
  стабильный/preview-каналы и SHA-256 обновлений сохранены.
- macOS остаётся на подтверждаемом пользователем DMG-обновлении; новый stock
  root-updater upstream не включён для брендированных клиентов.

## До стабильного тега

1. Собрать Windows x64 Support и Operator обычным workflow_dispatch без тега.
2. Проверить установленный Support: служба выключена → открыть окно → нажать
   кнопку → подтвердить UAC → получить готовность → подключиться оператором.
3. Повторить с отменой UAC, отключённым интернетом, остановкой службы через ОС,
   перезапуском приложения, portable Support и масштабом Windows 125/150/200%.
4. Проверить Operator OAuth/refresh/logout и отсутствие исходящих функций у Support.
5. Пройти остальные платформенные сборки, включая Android API 36 и macOS DMG.
6. Проверить обновление с `1.4.9-soft.6`: роль, настройки, ID и ключи сохраняются;
   неподходящий файл и неверный SHA-256 отвергаются; preview не приходит Support.
7. Только после тестирования создать preview, затем стабильный тег
   `v1.5.0-soft.1`. Ветка и артефакт Actions сами по себе не являются релизом.

Полная Windows-сборка и реальный UAC/служба не проверяются Flutter widget-тестами.
Тесты блока статуса находятся в `flutter/test/service_status_card_test.dart`.
