# Каналы обновлений SOFT.Connect.Desk

Приложение распространяется напрямую, без Microsoft Store, Google Play и
App Store.

## Что считается обновлением

- Обычный ручной запуск `Build branded clients` создаёт только временные
  артефакты GitHub Actions. Клиенты их не видят и установить их автоматически
  не могут.
- Тег вида `v1.4.9-soft.5-preview.1` создаёт GitHub Prerelease. Его получают
  только операторские устройства, на которых включено
  `Получать тестовые обновления`.
- Тег вида `v1.4.9-soft.5` создаёт Stable Release. Это единственный канал,
  используемый клиентскими Support-сборками по умолчанию.

Стабильный тег следует создавать только на уже проверенном коммите, который
был собран обычным Action и затем Preview-тегом.

## Защита обновления

В каждый Release автоматически добавляются:

- `update-manifest.json` с каналом, версией, именами, размерами и SHA-256;
- `SHA256SUMS.txt`;
- исходный архив соответствующего коммита.

Приложение проверяет соответствие манифеста GitHub Release и SHA-256
загруженного установщика до его запуска. Support и Operator выбирают только
пакет своей роли, ОС и архитектуры.

## Поведение платформ

- Windows: установленная и portable-версия могут скачать и запустить
  обновление автоматически, если включено `Автообновление`.
- macOS: приложение скачивает DMG, но macOS всё равно требует подтверждение
  пользователя. Без Apple Developer Program убрать системное предупреждение
  нельзя.
- Linux: приложение сообщает о новой версии и открывает нужный Release;
  формат установки зависит от дистрибутива.
- Android: приложение сообщает о новой версии и открывает Release. При
  распространении APK вне Google Play Android всегда требует подтверждение
  установки пользователем; бесшумная установка обычным приложением запрещена.
